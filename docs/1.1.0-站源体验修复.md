# 1.1.0 站源体验修复

## 1. 站源管理页开关 / 删除 / 排序后整页重新加载

**现象**：切换任一开关或删除任一站源后，页面回到「正在加载站源」转圈，连续操作被打断。

**根因**：`lib/ui/settings/source_management_page.dart` 中 `_SourceTile` 的所有操作结束都回调 `onChanged`，而它绑定的是 `_refresh()`；`_refresh()` 每次 `setState(_loading = true)` 并重新 `sourceRegistryFiltered()` 拉全量，因此每次操作都触发整页 loading。

**修复（乐观更新）**：操作时先改内存列表并 `setState` 立即渲染，再异步落库；失败才回滚并 Toast。页面只在首次进入时 loading 一次。

```dart
Future<void> _toggle(SourceEntry entry, bool value) async {
  final before = _allItems;
  setState(() {
    _allItems = [
      for (final item in _allItems)
        if (item.id == entry.id) item.copyWith(enabled: value) else item,
    ];
  });
  try {
    await AppScope.of(context).repository.sourceRegistryToggle(entry.id, value);
  } catch (failure) {
    if (!mounted) return;
    setState(() => _allItems = before);
    _toast('操作失败：$failure');
  }
}
```

删除与排序同理：`_remove` 先从 `_allItems` 移除再 `sourceRegistryRemove`；`_move` 先 `removeAt/insert` 换位再 `sourceRegistryReorder`，异常时用 `before` 回滚。

`_SourceTile` 改为回调注入，不再使用 `onChanged: _refresh`：

```dart
_SourceTile(
  entry: item,
  onToggle: _toggle,
  onRemove: _remove,
  onMove: _move,
)
```

同时给 `SourceEntry` 增加 `copyWith`（`lib/source_models.dart`），开关只改本地字段，不重新请求。

## 2. 主页「全部站源」面板只显示红果（1 个）

**根因**：`lib/ui/explore/source_actions.dart` 的 `pickSource` 只遍历内置 `store.sources`，未读取已导入的 `sourceRegistryFiltered()`。

**修复**：面板同时列出内置站源与已启用、已导入的站源；第三方站源用 `registry:<id>` 作为选项值，点击后直接进入 `SourceContentPage`。

```dart
List<SourceEntry> imported = const [];
try {
  final repository = AppScope.of(anchor).repository;
  imported = (await repository.sourceRegistryFiltered())
      .where((item) => item.enabled)
      .toList()
    ..sort((a, b) => a.order.compareTo(b.order));
} catch (_) {
  imported = const [];
}

options: [
  for (final source in store.sources) ChoiceOption(source.id, source.name),
  for (final entry in imported) ChoiceOption('registry:${entry.id}', entry.name),
],
```

选择处理：

```dart
if (value.startsWith('registry:')) {
  final id = value.substring('registry:'.length);
  SourceEntry? entry;
  for (final item in imported) {
    if (item.id == id) { entry = item; break; }
  }
  final chosen = entry;
  if (chosen == null || !anchor.mounted) return;
  await openPage<void>(
    anchor,
    (_) => SourceContentPage(store: store, entry: chosen),
  );
  return;
}
```

## 3. 范围说明

- 本分支收录 Dart 层修复与说明；完整 1.1.0 工程依赖 `assets/offline_sources/`（约 2.3MB）与预编译 `libduanju_core.so`（15.2MB），二进制未上传。
- 网页 / GitHub / GitLab / Gitee / Telegram / X 采集、站源检测、媒体保存均在 Go 原生核心中实现，必须与对应 `.so` 一起构建。
- 非 MacCMS 自定义格式站源目前内容页只给出格式提示；要支持任意自定义格式需扩展 Go 侧解析器与 Dart 侧渲染。
