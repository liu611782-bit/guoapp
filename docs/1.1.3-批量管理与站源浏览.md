# 1.1.3 批量站源管理与任意站源可浏览

## 批量操作

站源管理页新增右上角「⋮」菜单，所有的批量动作都作用于当前筛选结果（全部 / 有效 / 失效 / 未检测）：

- 全部开启、全部关闭（本地先改，再按 20 条一批 `sourceRegistryToggle` 落库，失败整批回滚）
- 删除当前列表（弹窗确认条数，一次 `sourceRegistryRemove` 传全部 id）
- 单个开关 / 删除 / 上下移继续沿用乐观更新，不再触发整页 loading

## 站源浏览兜底

- `isMaccmsEntry` 扩展：只要 `api` 是 http 地址（即使没有 apiType）就按 MacCMS 尝试，能解析的直接进入内容列表。
- 解析失败或非 MacCMS 时，页面不再只显示「自定义格式」：新增「用浏览器浏览」「复制地址」两个按钮，直接用外部浏览器打开该站源，避免死页面。
- 这样所有站源至少有一条可打开的路；要完全内置渲染任意格式，仍需扩展 Go 解析器与 Dart 渲染层。

## 卡顿 / ANR 处理

- 站源量可达 1000+，此前每次操作都重新拉全量并整页重建是卡顿主因之一，已改为本地更新。
- 健康检测与导入仍由 FFI 在主 isolate 同步执行，站源很多时会阻塞 UI；本轮先加 `android:largeHeap="true"` 降低 OOM 风险，批量检测建议后续分页/分批执行。
- 安装包仍为 arm64，minSdk 24；低内存机型建议先关闭不用的站源再检测。
