# 1.1.2 源市场（Dart 侧实现）

新增 `lib/ui/settings/source_market_page.dart`，在「站源管理」右上角以「源市场」入口打开，不依赖 Go 核心。

## 能力

- 读取内置 `assets/offline_sources/subscription_urls.txt` 的订阅线路，支持手动新增 / 删除，自定义线路持久化到 SharedPreferences。
- 扫描：Dart `HttpClient` 直连，4 并发、8 秒超时，记录 TTFB、体积、站源数量与格式（JSON / TXT / base64）。
- 解析：兼容 `[...]`、`{"sources":[...]}`、`{"sites":[...]}`、嵌套 JSON、纯文本每行一个 URL、base64 订阅。
- 失败分类：域名解析 / 连接失败、TLS 握手失败、超时、未解析到站源。
- 导入：把扫描成功的 payload 统一为 `{"sources":[{name,url,category,api,apiType}]}`，逐条调用 `repository.sourceRegistryImport`，结果汇总提示，部分失败弹出明细。
- 交互：勾选参与扫描的线路、全选/取消、扫描中线性进度、扫描结果状态色与「共 N 条 / 可用 / 异常」统计。

## 与 Go 采集页的关系

- `SourceCollectorPage`（网页 / GitHub / GitLab / Gitee / Telegram / X 采集）继续走核心 `sourceCollect` action。
- 源市场只负责「订阅线路扫描 + 批量导入」，两者入口都在站源管理页。
- 非 MacCMS 自定义格式站源的内容页仍给出格式提示；要渲染任意自定义格式需要扩展 Go 解析器。
